# Barbearia Central — demonstração Kit Digital

Projeto demonstrativo em React + Vite para apresentar o Kit Digital Express.

## Executar
1. Instale Node.js (versão LTS).
2. Execute `npm install`.
3. Execute `npm run dev`.

## Publicar na Vercel
- Importe este repositório na Vercel.
- Framework: Vite.
- Build command: `npm run build`.
- Output directory: `dist`.

## Antes de usar com um cliente
- Troque nome, textos, serviços, preços, endereço, horários e imagens.
- Substitua `demoPhone` em `src/App.jsx` por um WhatsApp fornecido e autorizado pelo cliente.
- Remova os avisos de demonstração apenas depois de substituir os dados fictícios.
- Confirme autorização para uso de fotos, marca e informações.
- Este projeto não coleta dados nem realiza pagamentos.

Preços, endereço e horários atuais são fictícios. Fotografias externas são ilustrativas.
